磁盘清理扫描器（独立版）使用说明
================================

这是一个 Windows 桌面程序，单文件、绿色免安装，不依赖 DeepSeek Harness、不需要联网、不需要 Node.js 或 Python。
全程只读：不删除、不移动、不修改任何文件。

适用系统
--------
Windows 10 / Windows 11（64 位与 32 位均可；程序使用系统自带的 .NET Framework 4.x，Win10/11 默认已安装）

文件
----
DiskCleanup.exe   主程序（约 52 KB）
使用说明.txt      本文件
Program.cs        源码（可删，留着便于审查或自行修改）

启动
----
双击 DiskCleanup.exe 即可打开窗口。

使用步骤
--------
1. 扫描路径默认 C:\，可改成 D:\ 或任意目录；右侧「浏览…」可选择文件夹
2. 大文件阈值默认 300 MB（扫描时单独列出超过该大小的文件）
3. 点「开始扫描」，窗口显示已扫描文件数、耗时和当前目录
4. 扫描完成后：
   - 表格按占用从大到小列出候选，绿=A 低风险、黄=B 需确认、红=C 先核实
   - 底部显示 A/B/C 三档合计
   - 点「打开报告」用系统浏览器打开 HTML 报告
   - 点「打开报告目录」定位到报告所在文件夹
   - 双击表格某一行，会在资源管理器里选中该路径
5. 报告自动保存到：文档\DSH-Scan\<盘符>-<时间>\，含 md / html / csv / json 四种格式

耗时参考
--------
扫描耗时取决于文件数量、磁盘性能、目录权限和杀毒软件实时扫描强度。
扫描期间可以正常使用电脑，但不要关闭程序；点「取消」可随时停止。

首次运行提示
------------
程序未做数字签名，若 Windows 弹出「已保护你的电脑」，点「更多信息」→「仍要运行」即可。
程序不联网、不写系统目录，只读取文件大小和名称。

分级含义
--------
A 低风险    缓存、日志、临时文件、更新残留等，一般可直接清理
B 需确认    个人数据（微信/QQ 文件、游戏录像、下载目录）或会影响软件功能，需先确认
C 先核实    来源不明、反作弊/远控/P2P 残留等，建议先查清是什么再处理
D 勿删      系统组件目录（WinSxS、Installer、DriverStore 等），报告里单独列出，不要手删

注意
----
- 程序只负责「找出来」，不负责删除；删除前请按报告里的「说明」操作
- 系统目录请用系统自带工具（磁盘清理、DISM），不要直接删
- 扫描结果基于路径和名称规则，不做病毒扫描，C 级不等于恶意软件
- 报告里的目录大小按文件逻辑长度累加，WinSxS 等含硬链接的目录可能偏大

命令行用法（可选，便于批量或计划任务）
--------------------------------------
DiskCleanup.exe --scan --path "C:\" --out "D:\reports\c-drive" --threshold 300
参数：
  --path       扫描路径（默认 C:）
  --out        报告输出目录（默认 文档\DSH-Scan\<盘符>-<时间>）
  --threshold  大文件阈值 MB（默认 300）
  --depth      目录统计深度 1-4（默认 2）
扫描完成后会在输出目录生成 summary.txt（一行一个统计值）和四种报告文件。
