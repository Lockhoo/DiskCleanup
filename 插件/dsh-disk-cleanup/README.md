# 磁盘清理扫描（dsh-disk-cleanup）

给 DeepSeek Harness 增加一个只读的磁盘清理排查工具：扫描指定磁盘或目录，生成一份和「人工排查」同款的清理报告。

## 功能

调用 `disk_cleanup_scan` 工具后，会：

1. 递归扫描目标磁盘（默认 `C:\`），统计文件数、总大小、顶层目录占用；
2. 识别常见可清理项并按风险分级：
   - **A 低风险**：Windows 更新缓存、系统/用户 Temp、日志、崩溃转储、显卡着色器缓存、浏览器缓存、IDE 缓存、`*-updater` 安装包残留、应用商店缓存等（删除前仍需按「说明」操作，个别项需要先停服务或使用系统清理工具）；
   - **B 需确认**：微信/QQ 文件、游戏录像、下载目录、WPS 缓存、UWP 应用缓存等个人数据；
   - **C 先核实**：`webhelper`、`SakuraFrp`、根目录大体积 `*.tmp` 等来源不明的残留；
   - **D 勿删**：WinSxS、Windows Installer、DriverStore、Package Cache、系统还原点。
3. 输出 4 个文件到输出目录（默认 `~/Documents/DSH-Scan/<盘符>-<时间戳>/`）：
   - `disk-cleanup.md`：完整 Markdown 报告；
   - `disk-cleanup.html`：带颜色（按大小分级）和排序的可视化报告，支持深色模式与窄屏横向滚动；
   - `disk-cleanup.csv`：可筛选的清单（UTF-8 BOM，Excel 可直接打开）；
   - `disk-cleanup.json`：原始扫描数据。

## 界面

插件在 Web 端右侧栏注册了一个「磁盘扫描」页：

1. 打开会话右上角的右侧栏展开按钮；
2. 在引导页里点「磁盘扫描」（或从更多工具中打开）；
3. 填写扫描路径与大文件阈值，点「开始扫描」；
4. 面板显示运行时长、A/B/C 三档合计和占用最大的候选，扫描结束后可「打开完整报告」（宿主用系统里的 Edge/Chrome 新窗口打开报告页），旁边还有「在标签页中打开」链接作为备用。

扫描在宿主后台进行（worker 线程），离开面板或切换会话不会中断；重新打开面板会恢复最近一次任务状态。

## 使用

对 agent 说：

> 扫描 C 盘，生成清理清单

或直接调用工具：

```json
{ "path": "C:\\", "depth": 2, "large_file_mb": 300 }
```

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `path` | `C:\` | 要扫描的盘符或目录；扫描子目录时规则会自动带上完整路径上下文 |
| `output_dir` | `~/Documents/DSH-Scan/...` | 报告输出目录 |
| `depth` | `2` | 目录占用表的聚合深度（1–4） |
| `large_file_mb` | `300` | 只列出不小于该大小的文件 |

## 安全性

- 全程只读：不删除、不移动、不重命名、不修改被扫描文件；
- 跳过符号链接/联接点，避免重复计数与跨盘遍历；
- 无权限的目录计入「不可读」，不会中断扫描；
- 扫描在 worker 线程中执行，不阻塞界面；耗时取决于文件数量、磁盘性能和杀毒软件实时扫描强度。

## 限制

- 仅根据路径/名称做启发式分类，不做病毒扫描或数字签名校验；
- 大小按文件逻辑长度累加，Windows 组件目录含硬链接，数值可能偏大；
- 「C 先核实」不等于恶意软件，删除前请自行确认；
- 扫描子目录时，D 级系统保留目录可能不在扫描范围内，报告会明确说明；
- 系统目录请使用系统自带清理工具（磁盘清理 / `DISM /StartComponentCleanup`）。
